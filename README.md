# Cybersecurity Awareness Bot — Part 2

A C# WinForms chatbot that helps you stay safe online through friendly,
interactive conversation — now with a full dark-themed desktop GUI!

## What It Does
Chat with the bot about any cybersecurity topic and it will give you
practical tips and advice. It remembers your name, picks up on your
mood, and keeps the conversation feeling natural and engaging.

## Features
-  Plays a voice greeting when the app launches
-  ASCII art logo displayed in the header
-  Covers 20+ topics including passwords, phishing, malware,
     ransomware, 2FA, encryption, VPNs, and more
-  Remembers your name and what topics interest you
-  Detects your mood and responds with empathy
-  Type "tell me more" to expand on any topic
-  Handles unknown inputs gracefully

## How to Run
1. Clone the repo
2. Open `CybersecurityBotGUI.csproj` in Visual Studio 2022
3. Add your `greeting.wav` and set Copy to Output Directory → Copy if newer
4. Hit **F5** and start chatting!

## Requirements
- .NET 8.0 · Visual Studio 2022 · Windows
